# MLP_with_standard_library
This project implements a Multi-Layer Perceptron (MLP) from scratch **using only Python’s standard library** and applies it to learning how to play Minesweeper.
No external libraries such as NumPy, PyTorch, or TensorFlow are used.  
All neural network components — forward propagation, backpropagation, and weight updates — are manually implemented.

# How to Run
git clone https://github.com/mingyu0304/MLP_with_standard_library.git
cd MLP_with_standard_library
python NN.py
